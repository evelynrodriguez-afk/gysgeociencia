Cómo publicar en GitHub
  1. Descarga el archivo JSON con el botón superior.
  2. Entra al repositorio de GitHub y abre la carpeta data.
  3. Reemplaza nosotros.json por el archivo descargado.
  4. Confirma el cambio (commit) y espera la actualización de GitHub Pages.
  5. Abre nosotros.html y verifica los cambios publicados.

Importante: esta primera versión no publica directamente desde el panel ni implementa permisos multiusuario reales. No ingreses contraseñas ni tokens en esta página.
